# Data Retrieval & Processing Improvements: Hub Refactor Pipeline

## 1. The "Batch Ingest" Utility (Permanent Tool)
Eliminate the need for temporary ingestion scripts by creating a permanent `scripts/maintenance/batch_ingest.py` tool.
*   **Mechanism:** The script will accept a structured JSON input file containing the slug, title, content, and parent metadata.
*   **Benefit:** Reduces token usage by avoiding repetitive Python boilerplate and speeds up the ingestion phase.

## 2. Structured Subagent JSON Output
Enforce strict JSON formatting for all subagent content generation tasks.
*   **Mechanism:** Subagents will be prompted to return a valid JSON object mapping slugs to their full OPS-compliant data structures.
*   **Benefit:** Allows for automated pipes from generation to ingestion, removing manual string escaping and formatting errors.

## 3. "Auto-Pilot" Discovery (Roadmap Automation)
Enhance the tracking system to programmatically identify the next targets for the refactor.
*   **Mechanism:** Add a `--next [N]` flag to the hub tracking logic to output the next N 'unfinished' slugs in the current pillar.
*   **Benefit:** Eliminates the manual research turn required to identify legacy nodes, maintaining momentum in the refactor cycle.

## 4. Grouping by "Logical Proximity"
Strategically batch subtopics based on shared mathematical foundations or physical principles.
*   **Mechanism:** Group topics like "Torque" and "Euler's Equations" in the same turn.
*   **Benefit:** Improves prose continuity, enables more natural cross-linking, and utilizes the subagent's local context more effectively for shared derivations.

## 5. Parallelized SVG Validation
Move SVG pre-rendering into a dedicated background process that triggers after every batch save.
*   **Mechanism:** Decouple `orchestrator.save()` from the main thread when rendering high volumes of new formulas.
*   **Benefit:** Decreases turn latency for large batches (5+ nodes).
