## 1. Executive Summary & System Overview

**Physics Lab** is a university-level digital physics encyclopedia engineered to deliver mathematically rigorous, topologically dense academic reference articles spanning senior undergraduate to graduate curriculum physics. It serves as the flagship domain module of **Project Terra**, an overarching scientific reference engine designed for multi-domain expansion (including future modules such as Chemistry Lab and Biology Lab).

### Key Architectural Paradigm
The project operates on a **dual-stack, dual-database architecture**:
1. **Web Frontend**: Built on a streamlined **FlightPHP** (PHP 8.0+) MVC framework handling URL routing, dynamic view rendering, MathJax SVG sprite sheet injection, and client-side interactive tool controllers.
2. **Dual Database Architecture (Dev Shards vs. Prod SQL)**:
   * **Local Development & Testing Layer**: Uses a sharded, flat-file relational JSON database stored on disk (`app/config/content/`). This enables fast offline content authoring, clean Git versioning, and zero-server-daemon testing.
   * **Production Deployment Target**: Designed to synchronize with a relational **MariaDB / MySQL SQL database** for high-concurrency production serving on a LAMP stack, backed by B-Tree indexing and FULLTEXT search queries.
   * **Shard-to-SQL Sync Engine**: `php scripts/maintenance/sync_node.php` and automated sync routines serialize physical JSON disk shards into MariaDB database tables.
   * **Current Deployment Status**: Currently developed and tested locally on macOS (`http://localhost:8000`), with active plans to test end-to-end production SQL deployment.
3. **Data Maintenance & Quality Pipeline**: A transactional **Python Content-Graduation Pipeline** (Python 3.10+) controlled via `gqs.py`, `integrity_shield.py`, `orchestrator.py`, and maintenance scripts. The pipeline enforces strict qualitative prose mandates and small-world topological connectivity under the **Organic Platinum Standard (OPS)**.

### Relational JSON Data Structure
Each subtopic node contains structured metadata including:
* `title`: Academic title.
* `standard`: `"platinum"` (or `"legacy"` during drafting).
* `parent_topic`: Parent discipline category slug (e.g., `relativity`).
* `content`: Pure academic HTML prose (`<p>` tags wrapping continuous text).
* `hero_math`: Key identity LaTeX equation snippet.
* `formulas`: Array of formula identifiers linked to the node.
* `neighbors`: Array of inter-topic anchor link slugs.
* `bridges`: Cross-pillar interdisciplinary bridge links.

### Formula Sharding & Vector Sprite Optimization
Formulas are stored separately from subtopics to allow multi-subtopic equation reuse and vector sprite caching.
* **Sharded Directories**: Formulas are partitioned across 100 subdirectories (`app/config/content/formulas/00/` through `app/config/content/formulas/99/`) to avoid file system directory lock bottlenecks.
* **Global LaTeX Index**: `app/config/formulas_latex_index.json` maps normalized LaTeX strings to canonical formula IDs for instant $\mathcal{O}(1)$ deduplication.
* **MathSprite SVG Compression**: MathJax expressions are pre-rendered into raw SVG path definitions and consolidated into `app/config/content/math_sprites.svg`. Subtopic views render lightweight `<use href="#math-path-<hash>"/>` SVG elements, reducing payload size for equations by >90%.

### B. Production SQL Synchronization Layer & Deployment Testing
To prepare for high-concurrency production deployments on LAMP infrastructure:
* **MariaDB / MySQL Target Database**: Production environments use a relational SQL database schema equipped with FULLTEXT indexing on titles, abstracts, and continuous prose for high-speed search and relational join capabilities.
* **Shard-to-SQL Synchronization Engine**: `php scripts/maintenance/sync_node.php <slug>` and automated database synchronization scripts parse flat-file JSON shards on disk and populate SQL tables (including subtopics, categories, formulas, and inter-topic edges).

## 3. The Organic Platinum Standard (OPS) & Pipeline Infrastructure

The centerpiece of Physics Lab's content governance is the **Organic Platinum Standard (OPS)**, enforced by `integrity_shield.py` and managed via `gqs.py` (Graduation Queue Stack CLI).

### Qualitative Prose Mandates
1. **The "In Media Res" Lead**: The opening sentence must immediately state a physical identity, law, or derivation. Introductory fluff (*"This article discusses..."*, *"In physics, ..."*) and mentioning the subtopic's title in the first 15 words are strictly forbidden.
2. **Zero-Artifact Continuous Prose**: Articles must consist strictly of `<p>` paragraph blocks. Bullet lists (`<ul>`, `<ol>`), markdown syntax (`**`, `__`), and heading fragments inside content strings are banned.
3. **Anti-Formulaic Integration**: Standard glossary transitions (*"defined by the following equation:"*, *"...where x is mass"*) are prohibited. Equations and variables must be integrated as grammatical continuations of physical sentences.
4. **Visual Texture & Math Density**: Every single paragraph of every article must contain at least **2 to 4 inline MathJax expressions** (e.g., \( g_{\mu\nu} \), \( |\Psi\rangle \)) to eliminate visual "walls of plain text".
5. **Explicit Variable Coupling**: Physical variables, operators, and state spaces must be coupled directly with their mathematical notation on first mention (e.g., writing *"metric tensor \( g_{\mu\nu} \)"* rather than *"metric tensor"*).
6. **Prose Depth Cushion**: Articles must clear a strict threshold of **650 to 1,000 words** of plain text. Overview nodes (`-overview` slugs) require **800 to 1,000 words**.

### Pipeline Utilities & Quality Guard Engines
* **Graduation Queue Stack (`gqs.py`)**: Unified session controller providing status dashboards, structure-compliant payload scaffolding (`template`), formula auto-seeding (`formula-auto-seed`), and batch compilation (`ingest`).
* **Transactional Sprint Orchestrator (`scripts/maintenance/run_gqs_sprint.py`)**: Executes a three-stage transaction loop (Savepoint commit -> Integrity arrest -> Final commit), rolling back workspace state automatically if MathJax rendering or OPS checks fail.
* **Aho-Corasick Multi-Pattern Auto-Linker (`scripts/maintenance/auto_linker.py`)**: Scans plain-text prose against registered synonyms and aliases, inserting relative anchor links in linear time ($\mathcal{O}(L+M)$) without catastrophic regex backtracking.
* **TF-IDF Context Affinity Engine (`orchestrator.py`)**: Calculates dynamic TF-IDF signatures across category hubs (filtering common background physics terms with a 60% document frequency ceiling) to prevent context leakage across disciplines.
* **Semantic Hallucination Shield (`scripts/maintenance/hallucination_shield.py`)**: Audits typeset LaTeX symbols against surrounding text anchors to detect notation drift or delimiter mismatches.
