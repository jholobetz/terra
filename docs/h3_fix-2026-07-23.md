## 1. Executive Summary & Diagnosis

During an inspection of `http://localhost:8000/physics/subtopic/rotational-dynamics`, a formatting violation was observed where raw HTML `<h3>` section headers broke up article text:

- `<h3>The Inertia Tensor and Frame Transformation</h3>`
- `<h3>Euler's Equations of Motion</h3>`
- `<h3>The Point Particle Limit</h3>`
- `<h3>The Symmetric Top and Analytical Solutions</h3>`
- `<h3>Poinsot's Construction and Topological Trajectories</h3>`
- `<h3>Astrophysical and Superfluid Applications</h3>`

### Organic Platinum Standard (OPS Rule #2) Violation
OPS Mandate #2 (**Zero-Artifact Continuous Prose**) explicitly prohibits block headers (`<h2>`, `<h3>`), lists (`<ul>`, `<ol>`), and markdown artifacts in article content. All subtopics must consist of high-density continuous academic paragraphs wrapped in `<p>` tags.

## 3. Root Cause Analysis

### Why It Escaped Integrity Shield
`integrity_shield.py` audited for markdown headers (`#`, `##`), word count floors, MathJax SVG density, broken links, spritified SVGs, and entity auto-links. However, **it lacked an explicit check for raw HTML header tags (`<h1>` to `<h6>`)**. 

As a result, these 12 legacy subtopics passed the audit despite violating OPS Prose Mandate #2.

---

## 4. Actionable Remediation Plan

### Step 1: Update `integrity_shield.py`
Add an explicit `check_forbidden_headers()` method to `integrity_shield.py`:
```python
def check_forbidden_headers(self):
    """Ensures subtopics do not contain forbidden HTML header tags (<h1-h6>)."""
    for slug, sub in self.all_subtopics.items():
        content = sub.get("content", "")
        if re.search(r'<h[1-6][^>]*>', content, re.IGNORECASE):
            self.errors.append(f"FORMATTING VIOLATION: [{slug}] contains forbidden HTML header tags (<h1-h6>). Only continuous <p> prose is allowed.")
```

### Step 2: Convert Headers to Continuous OPS Prose
Create a maintenance script (`scratch/fix_html_headers.py`) that converts `<h3>Header Title</h3>` tags into smooth, continuous academic paragraph leads:
```html
<!-- Before -->
<h3>The Inertia Tensor and Frame Transformation</h3>
<p>The fundamental equation of motion...</p>

<!-- After -->
<p><strong>The Inertia Tensor and Frame Transformation.</strong> The fundamental equation of motion...</p>
```

### Step 3: Database & Test Verification
1. Run `python3 scratch/fix_html_headers.py`.
