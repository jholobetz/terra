🔬 PHYSICS LAB: Technical Reference
Topic: API Quota & Usage Architecture (Agent vs. Script Client)
----------------------------------------------------------------

This document explains the architectural difference between how the coding agent (Antigravity) 
and custom Python scripts (like the database seeder) authenticate and consume Google AI compute, 
and why they experience different rate-limiting behaviors.

================================================================================
1. THE AGENT WORKFLOW (Antigravity & Subagents)
================================================================================
* Gateway: Routes through the Google DeepMind Agent Platform via secure RPC pipes.
* Authentication: Uses pre-authorized developer credentials configured during CLI installation.
* Compute Quota: High-volume, high-priority compute allocated specifically for agentic 
  coding sessions (pair programming, codebase analysis, testing).
* Rate Limits: Not subject to standard public API rate limits. Runs continuously without 
  throttling or 429 timeouts.

================================================================================
2. THE STANDALONE SCRIPT CLIENT (seed_physics_database.py)
================================================================================
* Gateway: Bypasses the agent platform, making direct HTTPS requests to the public Google 
  Developer API gateway (generativelanguage.googleapis.com).
* Authentication: Uses the developer API key retrieved from the local OS Keychain.
* Compute Quota: Subject to the standard developer billing plan associated with the API key.
* Rate Limits: Subject to public rate limits:
  - Free Tier: 15 Requests per Minute (RPM), 1,500 Requests per Day (RPD).
  - Pay-as-you-go Plan: Up to 1,000 RPM, unlimited daily requests (charged per token).

================================================================================
SUMMARY FOR DEVELOPMENT
================================================================================
* Conversations with Antigravity inside the CLI do not count against your API key quotas.
* Standalone scripts run outside of the agent context and require a personal API key, 
  which is subject to standard rate-limiting quotas (which is why custom scripts require 
  cooperative sleep delays like `time.sleep(6.0)` to run on the Free Tier).
